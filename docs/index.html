Read the failure, not just the score.

The detector thresholds grayscale images and finds 4-connected components. A bounded exact solver maximizes gated one-to-one matches, then minimizes squared centroid distance. The motion variant predicts with the last observed velocity; the ablation uses the last position. Tracks survive up to three missed frames. Ground truth never enters either tracker.

Velocity preserves identity through the original three-frame occlusion. But merged components corrupt the centroid observations: both methods switch identities in the original crossing. Recall alone hides this failure. Counts below each view describe the whole sequence, not the selected frame.
